## 🚀 Summary of Changes

This Pull Request delivers comprehensive administrative governance, full operational CRUD control over **Events** and **Opportunities/Bounties**, real-time **Broadcast Previewing**, live dashboard metric widgets, and JIT **Auth Metadata Hardening** for Uncooked V2.

---

### 🌟 Key Highlights & Modules Included

#### 1. 📊 Operations & Telemetry Dashboard (`/admin/dashboard`)
* **Live Event Catalog Widget**: Displays real-time campus events, categories, seats capacity tracking, and direct management links to `/admin/events`.
* **Live Opportunities & Bounties Catalog Widget**: Displays active internships, research roles, project bounties, company details, and candidate application counters with direct links to `/admin/opportunities`.
* **Telemetry Expansion**: Updated `/api/v2/admin/dashboard/stats` to stream real-time event and opportunity metrics alongside API/DB pool latency data.

#### 2. 📅 Full Event Operations & CRUD Desk (`/admin/events`)
* **Complete CRUD Lifecycle**: Create, edit, inspect, pause, draft, or delete any campus event or hackathon.
* **Full Field Management**: Admin controls over title, type, category, venue/location, date/time, seat capacity, ticket pricing, prize pool, banner image URL, and status (`Active`, `Paused`, `Draft`, `Cancelled`).
* **Capacity & Attendee Metrics**: Live capacity fill indicators and participant registration counters.
* **Filtering & Sorting**: Filter by category (`Tech`, `Campus`, `Cultural`, `Workshop`) or status (`Active`, `Paused`, `Draft`, `Cancelled`), with sorting by date, title, or capacity.

#### 3. 💼 Opportunities & Bounties Control Desk (`/admin/opportunities`)
* **Complete CRUD Lifecycle**: Post, edit, toggle active/closed, inspect candidates, or delete opportunities (internships, project bounties, research roles, full-time jobs).
* **Candidate Application Inspector**: Modal drawer allowing admins to view all student applicants, cover notes, department details, and application dates for each position.
* **Field Control**: Admin controls over title, company, role type (`INTERNSHIP`, `BOUNTY`, `PROJECT`, `FULL_TIME`), location, stipend/reward, deadline, requirements, and status (`ACTIVE`, `CLOSED`, `DRAFT`).

#### 4. 👥 User Governance & Profile Inspection (`/admin/users`)
* **Dynamic Table Sorting**: Multi-column sorting by Joined Date, Name, Email, Role, or Department with direction toggles (`ASC` / `DESC`).
* **Granular Profile Control Drawer**: Complete user audit drawer showing metadata, Auth Provider status, Phone, Department, Club, Interests, Verification state, Failed logins, Joined date, and Last active timestamp.
* **Instant Action Controls**: Direct email dispatch pre-population, automated password reset link trigger, account locking toggles, and role elevation (`USER` ↔ `ORGANIZER`).

#### 5. 📢 Communications & Live Broadcast Preview Hub (`/admin/communications`)
* **Interactive Recipient Search**: Auto-complete search bar to search registered users by name or email and select recipient chips when targeting specific users.
* **Media Attachment Section**: Add optional media / banner image URLs with live image thumbnail validation.
* **Real-Time Split-Screen HTML Email Preview**: Real-time rendering of the exact dark-themed HTML email template dispatched to recipients, including brand badge, header announcement, attached media, formatted text paragraphs, CTA button, and system footer.

#### 6. 🛡️ Authentication & JIT Metadata Sync (`/api/auth/migrate-login`, `middleware.js`)
* **Supabase User Metadata Sync**: Ensured JIT migration controller writes `{ role: user.role }` into Supabase Auth `user_metadata` to resolve 401/403 access loops on `/admin` routes.
* **Middleware Access Guard**: Hardened authorization checks for super administrative routes.
